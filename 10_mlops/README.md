# 10 — MLOps: Model Serving with FastAPI & Docker

**Goal:** Take a trained machine learning model from "a file on disk" to a **containerized REST API** that any system can call over HTTP — the core MLOps workflow of packaging and serving a model in production.

---

## Overview

This project demonstrates the end-to-end path a model takes to reach production:

```
train.py  →  model.pkl  →  app.py (API)  →  Dockerfile  →  running container
(train)      (artifact)    (serve)          (package)      (deploy)
```

A sentiment classifier (TF-IDF + Logistic Regression) is trained, saved as an artifact, served through a FastAPI REST API, and packaged into a Docker container so it runs identically on any machine.

> The model itself is intentionally simple (small self-contained dataset). The focus of this project is the **MLOps workflow**, not model accuracy.

---

## MLOps concepts demonstrated

| Concept | How it's applied |
|---------|------------------|
| **Train / serve separation** | Train once, save `model.pkl`; the API just loads the artifact |
| **Model serving** | A trained model exposed as an HTTP API (FastAPI) |
| **Containerization** | API + model + dependencies packaged with Docker → runs anywhere |
| **Reproducibility** | Pinned dependency versions in `requirements.txt` |
| **Isolated environments** | The container avoids "works on my machine" problems |


## How to run

### Option A — With Docker (recommended)

```bash
# 1. Build the image
docker build -t sentiment-api .

# 2. Run the container
docker run -d --name sentiment-test -p 8000:8000 sentiment-api

# 3. Test it
curl -X POST http://127.0.0.1:8000/predict \
     -H "Content-Type: application/json" \
     -d '{"text": "an amazing and brilliant film"}'

# 4. Stop it
docker rm -f sentiment-test
```

### Option B — Locally (without Docker)

```bash
pip install -r requirements.txt
python train.py            # regenerate model.pkl (optional, already included)
uvicorn app:app --reload   # starts the API at http://127.0.0.1:8000
```

Interactive API docs are auto-generated by FastAPI at `http://127.0.0.1:8000/docs`.

## API endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Health check |
| `POST` | `/predict` | Send `{"text": "..."}`, returns sentiment + confidence |

**Example response:**
```json
{"text": "an amazing and brilliant film", "sentiment": "pos", "confidence": 0.57}
```
